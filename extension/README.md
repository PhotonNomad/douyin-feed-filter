# 抖音视频屏蔽

按 BGM、博主或标签过滤抖音网页版推荐内容，支持标签关键词匹配和推荐流直播主播屏蔽。需要 Chrome / Edge 111 或更高版本。

## 安装

1. 如果使用 ZIP，先解压。
2. 打开 `chrome://extensions/` 或 `edge://extensions/`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本目录，确认其中直接包含 `manifest.json`。
4. 打开或刷新抖音网页版。

## 使用

- 点击视频右侧的屏蔽按钮，选择博主、标签或 BGM 并保存。
- 点击浏览器工具栏的扩展图标，管理规则、查看屏蔽记录、暂停过滤或调整按钮样式。
- 「标签包含关键词」按标签做包含匹配。例如 `穿搭` 可匹配 `#日常穿搭`；多个关键词分别添加，英文不区分大小写。
- 直播只提供主播规则。保存后尝试选择官方「不想看该主播」，必要时点击下一条；独立直播间没有下一条按钮时会提示返回推荐页。
- 「备份与恢复」可导出规则、历史和设置，支持合并、覆盖和撤销上次恢复。卸载前请保存备份，恢复后刷新抖音页面。
- 「诊断」可导出本地日志，分享前请检查其中的页面地址和视频信息。

更新时覆盖本目录中的文件，重新加载扩展并刷新抖音页面。更换安装目录或卸载可能丢失本地数据，请先导出备份。

仅支持 PC 网页版。BGM 识别依赖抖音返回的音乐字段，不进行音频指纹识别；接口和页面结构变化可能影响功能。

完整使用说明和问题反馈见[项目仓库](https://github.com/PhotonNomad/douyin-feed-filter)，数据处理方式见 [PRIVACY.md](PRIVACY.md)。
