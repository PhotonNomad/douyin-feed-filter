# 抖音视频屏蔽 0.5.25

适用于 Chrome / Edge 111+ 的抖音网页版扩展。按 BGM、博主或标签过滤推荐内容，规则和记录只保存在浏览器本地。

## 安装

打开 `chrome://extensions/` 或 `edge://extensions/`，开启开发者模式，点击「加载已解压的扩展程序」，选择本目录。

## 使用

- 在抖音视频右侧点击屏蔽按钮，选择博主、标签或 BGM 并保存。保存时会发送一次「不感兴趣」快捷键反馈。
- 点击浏览器工具栏的扩展图标，管理规则、查看屏蔽记录、上传按钮图片或调整按钮大小。
- 遇到问题，可在弹窗的「诊断」区导出日志。
- 更新后重新加载扩展，并完全刷新抖音页面。

仅支持 PC 网页版；BGM 识别依赖抖音官方数据，不包含音频指纹识别。直播不参与过滤。接口或页面结构变化可能影响功能。

数据处理方式见 [PRIVACY.md](PRIVACY.md)。
