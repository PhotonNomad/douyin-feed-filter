# 隐私说明

## 数据处理

扩展在浏览器内读取抖音页面和接口返回的视频、音乐、作者、标签及直播信息，用于匹配本地屏蔽规则。扩展不设数据收集服务器，不向开发者上传这些数据。

手动保存屏蔽规则时，扩展可能触发抖音自身的「不感兴趣」操作。相关反馈由抖音页面处理，适用抖音自身的数据处理政策。

## 本地存储

扩展使用浏览器本地存储保存：

- 启用状态和屏蔽规则，包括 BGM、博主、标签及标签关键词。
- 按钮图片和大小等设置。
- 最近的屏蔽记录。
- 诊断日志，包括识别与过滤结果、错误信息及抖音页面地址。
- 恢复备份前的撤销快照。

这些数据不通过扩展同步到其他设备。扩展不读取账号密码、Cookie 或浏览器浏览历史数据库，不采集视频音频，也不在其他网站注入内容脚本。

## 权限用途

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存本地规则、设置、记录、日志和撤销快照 |
| `https://*.douyin.com/*` | 在抖音网页上识别内容、过滤推荐响应并提供屏蔽与跳过操作 |

## 导出与分享

备份 JSON 包含规则、屏蔽历史和设置，不包含诊断日志或登录信息。诊断日志单独导出为文本。两类文件均下载到本机，不会自动上传。

这些文件可能包含页面地址、作者或视频信息、屏蔽偏好。请在公开分享前检查内容。

## 删除数据

可在扩展中移除规则、清空屏蔽记录和诊断日志。卸载扩展或清除扩展数据会移除其本地存储，包括撤销快照。

已下载的备份和日志文件不会随卸载删除，可由使用者自行删除。需要保留数据时，请在卸载前导出备份。
