# 抖音视频屏蔽（Chrome / Edge MV3 扩展）0.5.0

这是一个 PC 网页版抖音的推荐过滤扩展。它优先使用抖音接口返回的官方字段，例如 `music.id`、`music.title`、`author.nickname`、`text_extra.hashtag_name`。

当前版本不包含音频指纹识别，所以音乐过滤仍然只针对“抖音已经返回 BGM 标识”的视频。
直播内容不做 BGM / 博主 / 标签识别，也不显示屏蔽按钮；普通视频的作者正在直播时，仍按普通视频识别。
当卡片无法确认对应数据时，不会使用预加载的下一条视频数据兜底。

0.4.6 修正了 XHR 事件处理，不再劫持 `onload` / `onreadystatechange` 的赋值，避免影响抖音自身的请求回调。

## 功能

- 自动解析抖音网页版推荐流数据里的官方 BGM、博主和标签信息。
- 当前视频右侧操作栏会显示一个“不感兴趣”风格的心形图标按钮，位置与头像、点赞、评论、收藏、分享等原生图标对齐。
- 点击按钮后打开三行选择页：
  - 第一行：博主
  - 第二行：标签，可多选
  - 第三行：BGM
  - 底部提供“屏蔽”和“取消”按钮，可以同时选择多类内容后一起屏蔽
- 保存屏蔽规则时会同时发送一次抖音网页版的“不感兴趣”反馈（快捷键 R）。
- 命中任意规则后，优先在抖音 feed 接口返回给页面前移除对应视频，页面侧相当于没有收到该视频。
- 如果某一批推荐全部命中屏蔽规则，返回给页面的是空列表，但保留抖音原本的 `cursor` 和 `has_more` 字段。
- 当一批推荐全部被屏蔽时，扩展会尝试预取下一批数据，避免页面停在“加载中”；如果多次预取后仍无可展示内容，会回退为返回原始数据以保证页面可用。
- 扩展不代替抖音发下一批请求，也不合成滑动事件；是否加载下一批、显示“正在加载”或暂时划不动，都交回抖音原版逻辑处理。
- 支持按 BGM ID、标题、作者手动添加屏蔽规则。
- 支持开关扩展、清空屏蔽列表、取消屏蔽。
- 支持查看最近 200 条屏蔽记录，包括命中的规则和时间。
- 支持在扩展弹窗里选择按钮图标样式，并可自定义 emoji 或 1-2 个字符。
- 支持从本地选择图片作为按钮图标，自动缩放为最大 64px，并保持比例。
- 黑名单保存在浏览器本地，不上传数据。

## 安装

### Chrome

1. 打开 `chrome://extensions/`。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录 `douyin-bgm-filter-extension`。
5. 打开 [抖音网页版](https://www.douyin.com/)。
6. 点击浏览器工具栏里的扩展图标进行管理。

### Edge

1. 打开 `edge://extensions/`。
2. 打开“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择本目录 `douyin-bgm-filter-extension`。

## 设计原则

当前版本只做数据层过滤，不隐藏预加载视频、不修改视频卡片 DOM、不自动发送“下一个视频”快捷键。

扩展的处理方式是：

```text
抖音返回推荐流数据
    ↓
提取每个视频的官方 music 字段
    ↓
检查本地 BGM 黑名单
    ↓
feed 返回前：移除命中视频
整批都被移除：返回空列表，保留 cursor / has_more
后续加载：交给抖音原版 loading 和分页逻辑
```

这样体验上更接近“这个视频没有出现”，而不是“程序替我划走”。

## 使用流程

1. 加载扩展后打开抖音网页版。
2. 浏览推荐流几秒。
3. 当前视频右侧会出现一个心形屏蔽按钮，位置与原版操作栏对齐。
4. 点击后选择屏蔽音乐、博主本人或某个标签。
5. 保存后扩展会发送一次抖音的“不感兴趣”反馈；之后命中规则的视频会在 feed 响应层被移除。
6. 也可以点扩展图标，在“已屏蔽”里取消规则，或在“手动添加”里添加规则。
7. 在“按钮样式”里可以切换图标，或输入自定义 emoji / 字符。

如果列表里暂时没有目标 BGM，先继续浏览，等抖音返回该视频的官方 BGM 字段后再添加。

## 已知限制

- 只支持抖音网页版，不支持手机 App。
- 推荐流中的直播会被跳过，不参与识别和屏蔽。
- 音乐过滤只支持抖音已经返回 BGM 标识的视频。
- 博主和标签过滤依赖抖音返回的 `author` 与 `text_extra` / hashtag 字段。
- 抖音接口字段、页面结构更新后可能需要维护。
- 这是客户端过滤，不等于抖音推荐系统已经学会不再推该 BGM。
- 网络响应层过滤依赖抖音 feed 接口结构；接口变化时可能退化为无法过滤。
- 如果抖音原版逻辑没有对“空列表 + has_more”自动追加分页，页面可能需要用户再滑一次触发下一批请求。
- “不感兴趣”反馈依赖抖音网页版快捷键，抖音更新快捷键后可能需要调整。
- 需要支持 `content_scripts.world: "MAIN"` 的 Chromium 浏览器，建议 Chrome / Edge 111+。

## 数据与隐私

扩展只在浏览器本地保存：

- 扩展开关状态。
- BGM 黑名单。
- 按钮图标样式和大小设置。

不包含账号数据上传、第三方统计或云端同步。
