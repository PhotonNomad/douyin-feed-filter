# 抖音视频屏蔽

适用于 Chrome / Edge 的浏览器扩展，按 BGM、博主或标签过滤抖音网页版推荐内容，并支持在推荐流中屏蔽直播主播。

## 功能

- 屏蔽指定 BGM、博主或完全匹配的标签。
- 按标签关键词过滤，例如 `穿搭` 可匹配 `#夏日穿搭` 和 `#日常穿搭`。
- 屏蔽直播主播，并在推荐流中跳过对应直播。
- 管理规则、查看屏蔽记录、自定义按钮图片和大小。
- 备份和恢复本地数据，导出诊断日志。

## 安装

需要 Chrome / Edge 111 或更高版本，仅支持 PC 网页版。

1. 打开 `chrome://extensions/` 或 `edge://extensions/`，开启「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本仓库的 `extension` 目录（其中直接包含 `manifest.json`）。
3. 打开或刷新[抖音网页版](https://www.douyin.com/)。

如果拿到的是打包好的 ZIP，先解压，再选择解压后直接包含 `manifest.json` 的目录。

更新时覆盖 `extension` 目录中的文件，在扩展管理页点击「重新加载」，再刷新抖音页面。为保留本地数据，请使用同一个安装目录；更换目录或卸载前先导出备份。

## 使用

### 添加与管理规则

点击视频右侧的屏蔽按钮，选择博主、标签或 BGM 并保存。点击浏览器工具栏的扩展图标，可手动添加或移除规则、查看屏蔽记录，也可暂停过滤或调整按钮样式。

| 标签类型 | 示例规则 | 匹配结果 |
| --- | --- | --- |
| 完全匹配 | `穿搭` | 匹配 `#穿搭`，不匹配 `#日常穿搭` |
| 包含关键词 | `穿搭` | 匹配 `#穿搭`、`#日常穿搭`、`#夏日穿搭` |

关键词只检查标签，不检查视频正文、博主昵称或 BGM。输入可带前导 `#`，英文不区分大小写；多个关键词分别添加，任一命中即屏蔽。移除规则后，已过滤的视频需刷新页面才可能重新出现。

### 直播屏蔽

直播面板只提供主播规则。扩展在页面启动时记录抖音注册的主播屏蔽处理函数，手动保存后直接执行当前函数，由抖音自己的逻辑提交反馈并切换推荐。不会打开不感兴趣菜单或模拟按钮、键盘事件。

后续推荐响应中可识别的直播按主播规则在数据层移除，不重复点击官方反馈。已经载入的直播或无法解析的推荐卡片不受此次响应过滤影响。独立直播间的详情响应保持原样。

手动屏蔽时不点击下一条按钮，也不通过滚动切换直播。内部回调未捕获、已卸载或存在多个候选时会提示失败。更新扩展后需完整刷新抖音页面，以便从页面启动时开始记录回调；提交反馈后是否切换由抖音页面决定。回调属于抖音内部实现，页面更新后可能需要适配。

### 备份与恢复

在主弹窗中点击「备份与恢复」，可导出包含规则、屏蔽历史和设置的 JSON 文件。备份不包含诊断日志或登录信息。

选择备份文件后，检查预览并点击「确认恢复」：

- **合并**：保留现有规则，重复规则及设置以备份为准；合并后的历史保留最近 200 条。
- **覆盖**：用备份替换当前规则、历史和设置。

恢复前会保存一份本地快照，可通过「撤销上次恢复」还原。撤销会丢弃恢复后新增的数据。恢复或撤销后请刷新抖音页面。

卸载扩展会清除本地数据和撤销快照，但不会删除已下载的备份文件。卸载前请导出并保存备份。

## 工作方式与限制

扩展读取抖音页面和接口返回的视频信息，在可解析的推荐响应中移除命中规则的视频。手动保存普通视频规则时，会尝试触发抖音的「不感兴趣」快捷键；本地规则过滤与抖音的推荐反馈分别生效。

BGM 识别依赖页面返回的音乐字段，不进行音频指纹识别。直播不参与普通视频的 BGM 或标签过滤。抖音接口和页面结构变化可能影响识别、过滤或跳过行为。

## 问题反馈

遇到问题时，先重新加载扩展并刷新抖音页面。在[Issues](https://github.com/PhotonNomad/douyin-feed-filter/issues)中提供浏览器与扩展版本、页面类型、复现步骤和预期结果。

需要诊断信息时，在主弹窗中点击「诊断」，导出日志。分享前请检查日志中的页面地址、视频信息和规则，移除不希望公开的内容。

## 开发说明

- 扩展源码全部在 `extension`，没有构建步骤；改动后在扩展管理页重新加载并刷新抖音页面。
- 版本号写在 `extension/manifest.json`，固定三段数字，例如 `0.5.37`。
- 面向用户的变化记入[更新日志](CHANGELOG.md) 的「未发布」部分；页面交互改动需在抖音实际页面上验证，不要把本地模拟验证描述为实页验证。
